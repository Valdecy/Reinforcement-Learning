Training

ε falls from 1 to 0 over the first 60% of the steps. Each episode starts on a random open square. γ and the number of steps reset to suit each grid: long mazes need γ close to 1 so the treasure's value reaches the far squares.

Each open square splits into four triangles, one per action, tinted green for positive and red for negative Q(s, a). The chalk arrow is the action the agent takes there.

ε = 0.00

Chance the machine ignores its Q-table and moves in a random direction, fire included. At 0, a fully trained agent can only be tied.

You and the machine move at the same time, one step per turn. First to a treasure wins; reaching it on the same turn is a draw.

Arrow keys or WASD move you. You can also use the pad under the board or click a neighbouring square.
